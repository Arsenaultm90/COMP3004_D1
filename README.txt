# DragonEndPOS - Deliverable 1

## Minimum Requirements
- Qt 6.0.2 with the qmake build system
- C++11 compiler (g++, clang or MSVC)


## Build and launch
1. Open the .pro file in QT Creator
2. Build and run (Ctrl+R).

## Command line
qmake DragonEndPOS.pro
make
open DragonEndPOS.app
